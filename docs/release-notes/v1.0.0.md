# Graticule 1.0.0

Release date: 2026-09-28. Live at <https://mxtdnl.github.io/network/>.

Graticule is organisational network analysis that runs entirely in the browser, for teams of about 5 to 250 people. It is descriptive, not diagnostic: it reports network structure and never evaluates individuals. There is no backend, no telemetry and no third-party request at runtime.

This is the first release. It contains the work of spec phases 0 to 9 (phases 2 to 6R and 8 are built and awaiting the owner's formal acceptance; see `CLAUDE.md`).

## What is in it

**Data.** Members and directed, multi-layer ratings: four core layers (connection strength, valence, informal and formal collaboration) and twelve optional layers with suggested wording. CSV and XLSX import with downloadable templates and a validation report that lists every problem by row and never coerces a value silently. Keyboard matrix entry with paste from spreadsheets. "Not rated", "rated 0" and "does not apply" are kept distinct throughout. Projects are single `.ona.json` files (schema version 3, with migrations from versions 1 and 2); keeping a copy in the browser is optional and off by default.

**Surveys (respondent mode).** A whole-network survey run from Graticule with no server: personal links (or a survey file with short links), a mobile-first respondent flow with consent and name confirmation, answers encrypted on the respondent's device (ECDH P-256, HKDF-SHA-256, AES-256-GCM) and returned by file or pasted text, and a collection dashboard with import, duplicates, rejections, versions, mail-merge and non-responder lists.

**Analysis.** A Web Worker engine computing, per layer and for a weighted composite: strength, degree, betweenness, harmonic closeness, eigenvector centrality, Burt's constraint, effective size and clustering; density, reciprocity, components, Louvain communities and modularity, centralisation, E-I index and cross-group density; signed-layer in-valence and structural balance; multiplexity and the formal–informal comparison; resilience simulation; rank stability by resampling; data coverage with a warning threshold. Every metric matches NetworkX reference values within stated tolerances.

**Exploration.** An interactive canvas map with a persistent legend, four layouts, filters, search, ego view, shortest path, lasso and subgroup density, linked adjacency matrix, metrics table and layer comparisons; full keyboard operation and a tabular alternative for screen readers. Composite weighting with presets, signed-layer treatments and the live formula.

**Insights and presentation.** Rule-based observations worded as questions (potential brokers, peripheral members, possible overload, silos, negative clusters, formal/informal gaps), each showing its rule and linking to its view. Captioned saved views and a full-screen presentation mode. One-click anonymisation applied to every view and export.

**Exports.** Map as PNG (screen, 2× and 300 dpi print) and SVG with embedded fonts; member metrics, network metrics and formal–informal CSVs; a PDF summary report with the map, key metrics, insights, method notes, data coverage with survey response rates and an ethics statement. Every export respects Hide names and the option to leave out valence, energy and conflict.

**Documentation.** A user guide with anonymised screenshots, method notes defining every metric, rule and threshold, and a one-page help for survey respondents, all readable in the app from the Help menu.

## Quality

- Unit tests (Vitest), including the NetworkX fixture comparison, design-token enforcement and colour contrast.
- End-to-end tests (Playwright) against the production build under `/network/` with the Content Security Policy in force, including a release check of every view and export with no console error, CSP violation or request to another origin (`tests/e2e/release.spec.ts`).
- Zero axe-core violations in the Phase 8 audit at seven screen sizes; performance targets met at 250 members and about 10,000 ties (`docs/design-audit.md`).

## Known limitations

- Survey responses are confidential, not anonymous, and without a server a forwarded link can be answered by someone else (method notes, section 9).
- Only wave 1 is analysed; multi-wave comparison and a hosted collection service are out of scope for v1.
- Respondent mode was tested in Chromium, including phone emulation, but not yet on real iOS Safari and Android Chrome devices or with VoiceOver and TalkBack.
- On a phone the analyst workspace is read-only.
- The repository has no licence file yet.

## Upgrading

Nothing to do: project files from earlier builds (schema versions 1 to 3) open and are migrated automatically. Files saved by 1.0.0 record app version 1.0.0.
